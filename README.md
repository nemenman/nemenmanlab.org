# nemenmanlab.org

Website of the Nemenman group (theoretical biological physics, Emory University). Built with [Astro](https://astro.build) and Tailwind CSS, and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Editing content

Almost everything is a small data file in `src/content/`. Add, edit, or delete a file and push; the site rebuilds itself.

| What | Where | One file per |
|---|---|---|
| People (PI, members, alumni) | `src/content/people/<name>.yaml` | person |
| Photos of people | `src/assets/people/` | person (referenced from the YAML) |
| Group photos | `src/content/photos/<id>.yaml` + `src/assets/photos/` | photo (`latest: true` marks the one on the home page) |
| News | `src/content/news/<date-slug>.yaml` | item |
| Quotes (Smart Thoughts) | `src/content/quotes/<slug>.yaml` | quote |
| Favorite papers | `src/content/papers/<nn-author-year>.yaml` | paper |
| Press coverage | `src/content/press/<year-slug>.yaml` | story |
| Research directions | `src/content/research/<slug>.md` | direction |
| Old courses and events | `src/content/archive/<course>/<page>.md` | page |
| CV | `public/Nemenman_CV.pdf` | — |

Examples:

```yaml
# src/content/news/2026-11-new-paper.yaml
date: "2026-11"          # YYYY, YYYY-MM, or YYYY-MM-DD
text: "New paper: [Title of the paper](https://doi.org/10.xxxx/yyyy) in *Journal*."
```

```yaml
# src/content/people/jane-doe.yaml
name: "Jane Doe"
status: current          # pi | current | alumni
group: phd               # postdoc | phd | ms | undergrad | coadvised | visiting | rotation | summer | highschool
years: "2026–"
photo: "../../assets/people/jane-doe.jpg"
position: "…"            # for alumni: current position
url: "https://…"         # for alumni: link to their current page
```

When someone leaves the lab, change `status: current` to `status: alumni`, add `years`, `position`, and `url`, and keep the photo. Visiting, rotation, summer, and high-school students are listed by name only, without photos.

Fields named `review:` are notes for the editors and are never shown on the site. Yellow "Draft" boxes on the site disappear when the repository variable `SHOW_DRAFT_NOTES` is set to `false`.

Pages and layout live in `src/pages/` and `src/layouts/`. Site-wide settings (email, Google Scholar, X, navigation) are in `src/lib/site.ts`.

## Local preview

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static site in dist/, including forwarding pages for old wiki URLs
```

## Domain and old URLs

- Until DNS moves, the site is served at `https://nemenman.github.io/nemenmanlab.org/`. The workflow builds with `SITE_BASE=/nemenmanlab.org`.
- After the admin points `nemenmanlab.org` at GitHub Pages, do three things: add the custom domain in **Settings → Pages**, set the repository variable `SITE_BASE` to `/`, and set `SITE_URL` to `https://nemenmanlab.org`. Keep the domain's MX (email) records unchanged.
- Old MediaWiki addresses (`/~ilya/index.php/<Page>` and `?title=<Page>`) forward to their new pages. The map is `src/data/old-urls.json`. It is generated by `scripts/make-old-url-map.py` from the local crawl in `sources/`, which is not committed.
