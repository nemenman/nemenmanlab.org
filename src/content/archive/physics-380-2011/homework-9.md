1.  We have discussed in class that functions $x(t)$ can be represented by their Fourier transforms $x_\omega$. Transformation from a function to its transform and back is as easy as taking one integral. For functions that are periodic, so that $x(t+2\pi)=x(t)$ for any $t$, the result is even simpler, and the functions can be represented often by their *Fourier series* $x(t)=\frac{a_0}{2} + \sum_{n=1}^\infty \, [a_n \cos(nt) + b_n \sin(nt)]$, where $a_n = \frac{1}{\pi}\int_{-\pi}^\pi x(t) \cos(nt)\, dt, \quad n \ge 0$, and $b_n = \frac{1}{\pi}\int_{-\pi}^\pi x(t) \sin(nt)\, dt, \quad n \ge 1$ are called the Fourier coefficients of $x$. Let's explore how good such representations are. Let's study the *partial sums of the Fourier series* for $x$, denoted by $S_N[x(t)] = \frac{a_0}{2} + \sum_{n=1}^N \, [a_n \cos(nt) + b_n \sin(nt)], \quad N \ge 0.$. Calculate (analytically) the Fourier coefficients for the following three functions defined for $-\pi\le t\le \pi$. (a) $x(t)=\left\{\begin{array}{ll}-1,&t<0\\0,&t=0\\+1,&t>0\end{array} \right.$; (b) $x(t)=\left\{\begin{array}{ll}t/\pi+1,&t<0\\1,&t=0\\1-t/\pi,&t>0\end{array} \right.$; (c)$x(t)=(t/\pi-1)^2(t/\pi+1)^2$. Plot the first ten partial sums of the Fourier series for all of these functions to observe how the sums converge. Use one figure per function (that is, plot the ten sums on the same figure). Note that the Fourier coefficients decrease the slowest for the function that is discontinuous, (a), and the fastest for the function that is smooth, (c).
2.  Consider the following Langevin differential equation that we discussed in class: $\frac{dx}{dt}=-kx+c\eta$, where $\eta$ is a Wiener process, that is, it is a Gaussian variable with $\langle\eta\rangle=0$, $\langle\eta(t)\eta(t')\rangle=\delta(t-t')$.
    - Write simple program that would solve this equation using Euler stepping. That is, following our discussion in one of the previous homeworks, for a given $k$, $c$ and the temporal step size $\Delta t$, we can define $x_n\equiv x(n\Delta t)$, and then $\frac{x_{n+1}-x_{n}}{\Delta t}= -kx_n+\frac{c}{\sqrt{\Delta t}}\nu$, where $\nu$ is a Gaussian random variable with zero mean and unit variance. This then gives $x_{n+1}=x_{n} -kx_n\Delta t+c\sqrt{\Delta t}\nu$, which can be turned into a simple for-loop code for simulating a sequence of x's.
    - Simulate $N=1e5$ steps of this dynamics of $x$. Plot $x$. Describe what you see.
    - Take a Fourier transform of this $x$ using the Matlab build-in $fft$ function.
    - Plot (in log-log scale) the power spectrum (that is $\left|x_\omega\right|^2\equiv x_\omega x_{-\omega}$.
    - Using the expressions we derived in class, show that the power spectrum for this $x$ should look like $\langle x_\omega x_{-\omega}\rangle=\frac{c^2}{k^2+\omega^2}$. Compare this to your plot. Do they look similar? Think about why or why not. (Hint -- they will be similar for about half of your plot).
