Consider the following biochemical signaling circuit, which is supposed to represent the [Mitogen-activated protein (MAP) kinase](http://en.wikipedia.org/wiki/Mitogen-activated_protein_kinase) pathway, which is one of the most universal signaling pathways in eukaryotes. The total protein concentration is $x_{\rm tot}$ and unposphorylated, singly, and doubly poshporylated forms will be denoted as $x_0, x_1, x_2$ respectively, so that $x_{\rm tot}=x_0+x_1+x_2$. At the same time, a phosphotase with concentration $e_2$ is dephosphorylating the protein on both sites. 2.  We have discussed in class that functions $x(t)$ can be represented by their Fourier transforms $x_\omega$. Transformation from a function to its transform and back is as easy as taking one integral. For functions that are periodic, so that $x(t+2\pi)=x(t)$ for any $t$, the result is even simpler, and the functions can be represented often by their *Fourier series* $x(t)=\frac{a_0}{2} + \sum_{n=1}^\infty \, [a_n \cos(nt) + b_n \sin(nt)]$, where $a_n = \frac{1}{\pi}\int_{-\pi}^\pi x(t) \cos(nt)\, dt, \quad n \ge 0$, and $b_n = \frac{1}{\pi}\int_{-\pi}^\pi x(t) \sin(nt)\, dt, \quad n \ge 1$ are called the Fourier coefficients of $x$. Let's explore how good such representations are. Let's study the *partial sums of the Fourier series* for $x$, denoted by $S_N[x(t)] = \frac{a_0}{2} + \sum_{n=1}^N \, [a_n \cos(nt) + b_n \sin(nt)], \quad N \ge 0.$. Calculate (analytically) the Fourier coefficients for the following three functions defined for $-\pi\le t\le \pi$. (a) $x(t)=\left\{\begin{array}{ll}-1,&t<0\\0,&t=0\\+1,&t>0\end{array} \right.$; (b) $x(t)=\left\{\begin{array}{ll}t/\pi+1,&t<0\\1,&t=0\\1-t/\pi,&t>0\end{array} \right.$; (c)$x(t)=(t/\pi-1)^2(t/\pi+1)^2$. Plot some the first ten partial sums of the Fourier series for all of these functions to observe how the sums converge. Use one figure per function (that is, plot the sums on the same figure). Note that the Fourier coefficients decrease the slowest for the function that is discontinuous, (a), and the fastest for the function that is smooth, (c).
3.  A common signaling element in cells is the so called Incoherent Feedforward Loop: $s$ is a signal, which activates the response $r$ and the intermediate *memory* node $m$. The intermediate node then suppressed the output: $\begin{array}{l}\frac{dr}{dt}=-k_{rr}r+k_{rs}s-k_{rm}m\\\frac{dm}{dt}=-k_{mm}m+k_{ms}s\end{array}$. Repeat the procedures we've done in class to calculate the frequency dependent gain $g_\omega$ for this system. Plot the curve for $k_{mm}\ll k_{rr}$ and $k_{mm}\gg k_{rr}$. Explain the differences. *Graduate students:* Incorporate Langevin noise into the system and calculate the SNR for it.
